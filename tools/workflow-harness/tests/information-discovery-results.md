## Delivery defect and regression scope

The source installation used `.agents/skills/`, while its policy still linked
to the repository-root `skills/` distribution layout. The source links were
corrected for that installation; this distribution keeps `skills/` links and
documents how consumers adapt them. A further actual defect was
that Rust delivered policy text without its source location. Session requests
and independent check inputs now carry the configured policy path as JSON and
identify the base directory for relative links. This supports other configured
policy locations without hard-coding the current installation into the runtime.

- The Python regression exercises `prepare_resolver` through `model_view` and
  `verify_prepared`, then resolves every delivered local policy file and section.
- The Rust regressions read the locator from actual Coordinator, Resolver and
  independent-check inputs and open a referenced file. The policy is outside
  the fixture workspace, so workspace-relative guesses would not suffice.
- These tests establish delivery and reachability. They do not establish sound
  reasoning, arbitrary direct-call coverage or adoption by a running worker.

Validation completed:

  `test_validate_current_frontier_skill_bundle.py` and

## Observed synthetic execution

Inputs and assessment protocol are in [information-discovery-cases.md](information-discovery-cases.md).
The source exercise used a disposable local workspace. Relevant actual outputs
are summarized here so the conclusions do not depend on it surviving.

1. **First delegation:** the outgoing question asked which changes to appointment
   decisions, supporting information or its preparation could improve completed
   appointments within the staffing budget, and which next inquiry would
   distinguish promising directions. The three classifiers became starting
   points. The owner created `research-detail.md` and retained unresolved scope.
2. **Routing:** the executor replaced `working-plan.md`, retained its old text,
   implemented a consumer of current unit responsibilities in `candidate.py`,
   checked coverage for all 32 requests/eight units, and ran the supplied evaluator.
   `python3 evaluate.py baseline.py` returned 8/32 (0.25);
   `python3 evaluate.py candidate.py` returned 32/32 (1.0). No score-driven revision
   followed. The export was actually 175 bytes; the catalog's 240-byte estimate
   was not mistaken for a measured size. An unverified conflicting assistant
   draft did not override the current reference. The candidate retains the old
   fallback for missing units; this fixture did not validate that fallback.
3. **Local implementation control:** the executor fixed the reversed adapter
   columns, wrote the actual next task and ran `python3 check.py`, which returned
   `adapter contract passed`. No broader research or extra owner was added.
4. **Explicit local-query control:** the outgoing question compared only parsers
   A and B on the quoted-comma rule. Missing source locators remained unknown;
   the executor did not invent outcomes or expand the task.
5. **Recovery:** the owner replaced the encoder-only assignment and prepared a
   follow-up explicitly superseding its old restriction. In a subsequent stage,
   an idle synthetic worker first acknowledged the old instruction without
   executing it. After the owner delivered the correction and authorized local
   reading, the worker read the corrected task, goal and original inquiry, then
   inspected only the local source receipt, catalog and export. Its actual return
   confirmed the small export and recommended checking consumer coverage before
   a probe. It did not train, download, run an experiment or select a final route.

The executors participated in the prior audit and knew the repair background.
These are independent informed rehearsals, not blind trials. A fresh-context
agent could not be created because the conversation's agent-thread limit was
reached. The routing and adapter work shared a measured 142.317-second window,
excluding earlier reading. Full token, CPU, memory and isolated task costs were
not metered. No causal efficiency improvement follows from these observations.

## Deployment boundary

The source audit did not establish a newly unsupported restriction in the
limited current assignment it inspected. It did not rewrite that campaign's
route, restart work or alter historical results. That limited inspection does
not certify every live worker. The next material direction choice or relevant
recovery is the next applicable use of the changed discovery rules; ordinary
selected construction stays within its existing commitment.

Native hooks remain optional and scoped. A source change or rebuilt executable
does not update an already issued prompt, prove a long-running process loaded
new code, or correct an unobserved worker. Existing owners must apply a concrete
correction before affected future use when one is found. Production benefit and
broader host coverage remain unverified.
